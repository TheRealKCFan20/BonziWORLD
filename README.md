## Dependencies
- Node.js and npm
- Ruby
- Scss/Sass
- Git
- Cordova (Optional)
- Grunt
- Winston

## Setup
In a terminal and/or command prompt, navigate to where you'd like BonziWORLD to be placed and run the following:
```
git clone https://github.com/TheRealKCFan20/BonziWORLD
cd BonziWORLD
```

### Client
```
cd src
npm install
grunt build_www
cd ..
```

### Server
```
cd server
npm install
node index.js
```
